# Gophermart 
Diploma project for Yandex Practicum GO course

## Getting started
### Prerequisites
- go
- docker
### Installation
1. Clone the repo
```
$ git clone https://github.com/dmitastr/yp_gophermart.git
$ cd yp_gophermart
```
2. Edit config/gophermart_app.env file 

### Run the project
1. Build
```
$ go build -o gophermart ./cmd/gophermart
```
2. Execute
```
$ go build -o gophermart ./cmd/gophermart
```
